# Security policy

## Reporting a vulnerability

Do not report credentials, tokens, private account information, or exploitable
details in a public GitHub issue.

Send a private report to `emirsemenov@yahoo.com` with:

- the affected route or component;
- reproduction steps;
- expected and observed behavior;
- the potential impact;
- a suggested mitigation, if available.

Do not include Pinterest App Secrets, access tokens, refresh tokens, Auth.js
secrets, session cookies, or passwords in the report.

## Supported version

Security fixes are applied to the latest version on the default branch. Public
deployments intentionally exclude connected credentials; the private studio is
restricted to the configured owner identity.
